# NFL-Research

My app to help me with the NFL Researches.

## Installation

Install directly from GitHub:

```bash
pip install git+https://github.com/MocTalox/NFL-Research.git
```

For a specific version:

```bash
pip install git+https://github.com/MocTalox/NFL-Research.git@v1.0.0
```

## Usage

```python
from nfl import something

result = something(...)
```

## Development

Clone the repository:

```bash
git clone https://github.com/MocTalox/NFL-Research.git
cd NFL-Research
```

Install in editable mode:

```bash
pip install -e .
```

Run the tests:

```bash
pytest
```

## Requirements

* Python 3.10+
